# Projects
I've been extremely lucky to be involved in many exciting projects that were the result of hard work and collaboration with many exceptional people.
I'm proud of all of the below work, but please note, almost none were solo projects.

## Piechlab projects
- Code in Place - codeinplace.stanford.edu 
        Lead software development for the Code in Place platform, which offers live CS courses with thousands of teachers to the world.
- Code for Humanities - codeforhumanities.stanford.edu
        Co-taught a 2 week, 9-5 programming + AI course to a group of Stanford humanities professors.
- ide.stanford.edu
        Built an in-browser IDE for beginner programmers that has been used to create millions of projects by coders in over 150 countries.
- Python in Whatsapp - https://whatsapp-in-python.web.app
        A way to share and run Python programs over Whatsapp.
